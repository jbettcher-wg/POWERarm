# SIMD/FP instruction gaps on the M2 GCC ladder (2026-09-16, powerarm-m2/gcc)

These are the gaps the W6 ladder hit, for W2 (branch `powerarm-m2/simd-gaps`), which owns all SIMD/FP
instruction work.

## Already translated on powerarm-m2/gcc (don't redo)

| Encoding | Instruction | Commit | Test |
|---|---|---|---|
| LD1/ST1 single structure (`LD1_sngl_*`, `ST1_sngl_*`) | `ld1 {v31.d}[1], [x2]` (0x4d40845f, Debian ld.so) | 6023c6ec2 | A64Frontend `simd_struct1` |
| LD2/ST2 multiple structures (opcode 1000 in `LDx_STx_mult`) | `ld2 {v30.16b, v31.16b}, [x1]` (0x4c40883e, binutils `as`) | 678769e5a | A64Frontend `simd_struct2`. Checklist N10 is `in progress`: LD3/LD4/ST3/ST4 are still open |

| Rung | Command | First unimplemented word | Instruction | Where |
|---|---|---|---|---|

| 3 | `gcc -O2 -c hello.c`; any `/usr/bin/sh -c` | 0x4e012080 | `tbl v0.16b, {v4.16b, v5.16b}, v1.16b` (TBL, 2 tables) | glibc `strspn` |
| 3 | `as hello.s -o hello.o` | 0x4d40c2ff | `ld1r {v31.16b}, [x23]` (LD1R_1) | `as` |
| 4 | `gcc hello.o -o hello` (driver, then collect2/ld) | 0x4e012080 | TBL (as above) | glibc |

Reproduce any of these with `POWERARM_SILENTLOG=0 POWERARM_OUTPUTLOG=stderr POWERARM_ROOTFS=ArchLinuxARM-m2
POWERarm <cmd>`. Commit 092b387d7 logs the word even when the guest catches SIGILL itself (cc1
does). The harness job `alarm.hello-build` shows the TBL stop on both kernels.

Notes:
- `(undecoded)` is LSE (`casal` etc.) in libstdc++/libgcc outline atomics. They're only
  selected when HWCAP_ATOMICS is advertised, and POWERarm doesn't advertise it.
- The ST2/ST3/ST4 single-structure rows are in libffi (Guile), which isn't on the gcc path.
- The table predates LD2/ST2 multiple structures landing on this branch. Those don't appear in
  it because they decode through `LDx_mult_*`, which already had a handler.

## Status on powerarm-m2/simd-gaps (W2)

Every stop and every row of the census above is translated, with Pi-golden tests in
A64Frontend (`simd_table`, `simd_struct`, `simd_gaps`, next to `simd_struct1`/`simd_struct2`).
The LD1/ST1 and LD2/ST2 translators from this branch were folded into one implementation
each when `powerarm` was merged (see that merge commit). The reproducers above now finish:

| Rung | Command | Result |
|---|---|---|
| 2 | `cc1 -version` | exits 0, output identical to the Pi (SSHL translated) |
| 3 | `as hello.s -o hello.o` | exits 0 (LD1R translated) |
| 3 | `gcc -O2 -c hello.c` | exits 0, `hello.o` byte-identical to the Pi (TBL translated) |
| 4 | `gcc hello.o -o hello`, `./hello`, `/usr/bin/sh -c` | all exit 0 |

The LSE `(undecoded)` rows stay out of scope while HWCAP_ATOMICS is not advertised.
