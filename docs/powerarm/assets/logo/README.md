# POWERarm logo files

All PNGs have transparent backgrounds. SVGs are plain rects — no fonts, no filters,
safe for READMEs, favicons and desktop themes.

## Mark (SVG, scalable)
mark/powerarm-mark-color.svg          deep pair, for light grounds
mark/powerarm-mark-color-on-dark.svg  light pair, for black grounds
mark/powerarm-mark-black.svg          one ink
mark/powerarm-mark-white.svg          one ink, knockout
mark/powerarm-mark-twotint-light.svg  black + grey
mark/powerarm-mark-twotint-dark.svg   white + grey

## Icon geometry (thicker bars, wider gap — use below ~32px)
icon/powerarm-icon-24-*.svg
icon/powerarm-icon-16-*.svg

## Raster
png/mark/    512 / 256 / 128 / 64 / 32 px
png/icon/    16, 24, 32, 48 px (icon geometry)
png/lockup/  mark + wordmark, horizontal and stacked, light and dark, 4x

## Favicon
Use icon/powerarm-icon-16-color.svg for the SVG favicon and
png/icon/powerarm-icon-16-color-16.png + -32.png as raster fallbacks.
Use the -on-dark files where the UI chrome is dark.
