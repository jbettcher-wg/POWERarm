# lat = one dependency chain; tp = four independent chains. Core cycles are derived

# a quiet box (see docs/powerarm/MEASUREMENT-METHOD.md 1).

# WHAT THIS MEASURES: one sequence in isolation. It therefore says nothing about
# register pressure or icache footprint, which is why it can rank a lowering but
# cannot speak to checklist P1 (pressure) or P4/P6 (fetch).
#
# FINDINGS THAT CHANGED A DECISION
#   * Static instruction count can invert. sshl_reg13 is 13 instructions and 9.22
#     cycles; xscvhpdp is 1 instruction and 40.66. addv32_rot4 uses MORE
#     instructions than addv16_3 and is cheaper on both columns.
#   * ISA-OPPORTUNITIES 3.12 (three-way compare -> setb) is a REGRESSION on both
#     columns: threeway_isel 8.07/2.19 against threeway_setb 10.21/2.78. setb reads
#     a whole CR field; isel reads one bit and its two li's sit off the chain.
#   * ISA-OPPORTUNITIES 3.13 (pre-index STP -> stdu) is a small throughput
#     regression, 2.37 -> 2.45, confirming that doc's own "cracked on POWER9" note.
#   * ISA-OPPORTUNITIES 3.9 (remainder via modsd) is a real win: modsd costs exactly
#     what divd alone costs (21.19 vs 21.18 lat), so the mulld+subf it replaces are
#     pure added latency -- 28.24 -> 21.19 lat, 9.93 -> 8.08 tp.
#   * The lane-test fusion, already landed, measures 27.23 -> 1.25 cycles: 21.8x,
#     not the 5x its 10->2 instruction count implies. Its value is in staying in CR;
#     vcmpequb_rc_mfocrf, which routes through a GPR, is 14.17.
#   * ISA 3.0 buys nothing for a vector context spill: ctx_roundtrip_stxv_lxv 15.20
#     against ctx_roundtrip_stxvd2x_lxvd2x 15.21. Store-forward bound, not
#     instruction bound -- and 15.2 cycles per avoided spill prices checklist P1(b).
#   * mfvscr/mtvscr are 1 instruction, 16.15 cycles, with tp == lat: wholly
#     unpipelined. The FP16 work routed around VSCR on instinct and was right.
#
