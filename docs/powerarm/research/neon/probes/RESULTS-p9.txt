# neon_bench_p9 output. 2026-10-17, POWER9 (44 cores, SMT4), pinned to CPU 108, box idle.
# The probe is native ppc64le and does not run under POWERarm.
# Built: clang -O2 -mcpu=power9 -DP9=1 -o neon_bench_p9 neon_bench_p9.c
#   (clang is the NATIVE ppc64le compiler on this box; the host gcc is ppc64le too,
#    but a shell running under POWERarm sees the rootfs's aarch64 gcc instead.)
# Run:   taskset -c 108 ./neon_bench_p9      -- two runs agreed to three decimals.
#
# VALIDITY GATE: g_add must read ~2.0 cycles, matching the calibration chain. It reads
# 2.01 here. A run where it drifts was taken on a contended box and is void -- which is
# what makes this measurement safe to take without reserving the machine.
#
# lat = one dependency chain; tp = four independent chains. Core cycles come from the
# time base against a calibrated dependent-add chain, so they do not depend on the
# governor -- the one measurement here that needs no quiet box for its UNITS, though
# the figures below were taken on an idle one anyway.
#
# WHAT THIS MEASURES: one sequence in isolation. Silent about register pressure and
# I-cache footprint, so it can rank a lowering but cannot speak to checklist P1
# (pressure) or P4/P6 (fetch).
#
# ATOMICS AND BARRIERS -- the numbers checklist P7 had been quoting from the pipeline
# guide rather than from this machine:
#   sync 53.40   lwsync 12.09   isync 10.06   eieio 53.41
#   larx/stcx. uncontended pair 69.49 (identical at both widths)
#   * eieio costs the SAME as a full hwsync here, so there is no cheap ordering
#     primitive below lwsync on this part. lwsync at 12.09 is the floor.
#   * A fence's cost depends on what is pending behind it: lwsync alone is 12.09, but
#     behind a store -- the shape a release actually takes -- it is 32.26. The guide's
#     "+14" understates the release-store case by 2.3x.
#   * So a fenced RMW is roughly 53.4 (leading hwsync) + 69.5 (the pair) + 10.1
#     (trailing isync) = about 133 cycles, and an acquire load about 67. P7 established
#     that the LEADING hwsync cannot move (herd7 rejected trailing-sync, and separately
#     rejected ctrl+isync), which leaves the trailing isync -- 10.1 of those 133, under
#     8%. That is the whole size of the remaining fence lever.
#   * ISA-OPPORTUNITIES 3.14's mcrf half, already landed, is worth 20.59 -> 10.07: about
#     10.5 cycles, 15% of an unfenced atomic.
#
# ISA 3.0 AMOs: REJECTED, 11x SLOWER than the loop they would replace.
#   amo_ldat_add 796.23   amo_stdat_add 504.69   against rmw_fetchadd_larx 70.23.
#   All four of lwat/ldat/stwat/stdat do execute here and do modify memory, so this is
#   not an availability problem. lat == tp for both (796/800 and 505/501), i.e. wholly
#   unpipelined, which together with the magnitude is the signature of a firmware or
#   hypervisor assist rather than a hardware atomic. Architecturally present, and
#   practically unusable. Subtracting the two `mr` the even-RT workaround costs changes
#   nothing at this scale.
#
# OTHER FINDINGS THAT CHANGED A DECISION
#   * Static instruction count can invert. sshl_reg13 is 13 instructions and 9.22
#     cycles; xscvhpdp is 1 instruction and 40.66. addv32_rot4 uses MORE instructions
#     than addv16_3 and is cheaper on both columns.
#   * ISA-OPPORTUNITIES 3.12 (three-way compare -> setb) is a REGRESSION on both
#     columns: threeway_isel 8.05/2.18 against threeway_setb 10.20/2.77.
#   * ISA-OPPORTUNITIES 3.13 (pre-index STP -> stdu) is a small throughput regression,
#     2.37 -> 2.45, confirming that doc's own "cracked on POWER9" note.
#   * ISA-OPPORTUNITIES 3.9 (remainder via modsd) is a real win: modsd costs exactly
#     what divd alone costs (21.16 vs 21.14 lat), so the mulld+subf it replaces are pure
#     added latency -- 28.22 -> 21.16 lat, 9.93 -> 8.05 tp.
#   * The lane-test fusion, already landed, measures 27.23 -> 1.25 cycles: 21.8x, not
#     the 5x its 10->2 instruction count implies. Its value is in staying in CR;
#     vcmpequb_rc_mfocrf, which routes through a GPR, is 14.17.
#   * ISA 3.0 buys nothing for a vector context spill: ctx_roundtrip_stxv_lxv 15.20
#     against ctx_roundtrip_stxvd2x_lxvd2x 15.21. Store-forward bound, not instruction
#     bound -- and 15.2 cycles per avoided spill prices checklist P1(b).
#   * mfvscr/mtvscr are 1 instruction, 16.15 cycles, with tp == lat: wholly unpipelined.
#
